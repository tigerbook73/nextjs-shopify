# CLAUDE.md 生成要求

本文件定义 CLAUDE.md / AGENTS.md 的内容规范，供 `/init` 命令或人工撰写时参考。
分为两部分：**一、通用内容要求**（人工维护）和 **二、工具要求**（工具自动写入）。

---

## 一、通用内容要求（人工维护）

重新生成时，AGENTS.md 应覆盖以下内容。⚠️ 标注为容易遗漏的高价值内容。

### 必要章节

- **常用命令**：开发、构建、测试、代码生成等常用命令，含必要的前置条件说明
- **环境配置**：必填环境变量、本地证书、外部服务依赖
- **技术栈**：主要依赖及其用途，标注版本（特别是有破坏性变更风险的依赖）
- **架构概览**：目录结构 + 各层职责，重点说明"为什么这样分层"而非只列文件在哪里
- **测试规范**：测试分层、各层覆盖范围、豁免条件、测试文件路径
- **提交规范**：commit message 格式要求

### ⚠️ 容易遗漏的高价值内容

- **关键设计决策**：非显而易见的架构选择，说明原因和约束
  - 示例：为什么选 X 而非 Y、某个模式的适用边界、已踩过的坑
- **版本特殊行为**：使用了非稳定版本或有已知破坏性变更的依赖时，说明与通常假设的差异
- **外部系统约束**：第三方 API 限制、认证流程的特殊步骤、不能在 CI 中重现的场景
- **禁止事项**：明确列出"不能做什么"，比散落在正文中更有效
  - 示例：哪些文件禁止手动编辑、哪些命令不能在生产环境运行
- **文件生成规则**：哪些文件由工具自动生成，禁止手动编辑
